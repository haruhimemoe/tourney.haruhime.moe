How hosts enter match results.

## Type the score

Open the match from the schedule page and type each side's score. It has to fit the round's best of: in a best of 9 the winner has 5.

You can also list the maps played, each with its slot and winner. With maps listed, the score is counted from them.

## Fill from an mp link

Paste the match's osu! multiplayer link and say how many warmups to skip. tourney reads the lobby, matches each game to the round's pool and each player to a team's roster, and shows a preview: the score, the maps and anything it thinks you should check. Nothing is saved until you press **Save result**.

Each host can fill 20 mp links an hour.

The preview can list these problems:

| Problem | What it means |
| --- | --- |
| Off pool | A map isn't in the round's pool. |
| Unknown player | A player isn't on either team's roster or subs. |
| No side | A player can't be placed on either side. |
| Aborted | A game was aborted. |
| In progress | A game is still being played. |
| Duplicate pick | A pool slot was played twice. |
| Tie | A game ended in a tie. |
| After win | A game was played after the match was already won. |

Saving is blocked while the preview shows an off pool map or an unknown player, until you tick that you checked it.

Reading an mp link needs the round's pool. If the round has none, or pools.haruhime.moe is down, type the score in instead.

## Picks and bans

If the edition has pick and ban rules, add the order: who banned and picked first, then each protect, ban and pick. tourney checks it against the rules and the round's pool.

## Forfeits and undo

**Forfeit** sends the other side through. **Undo result** clears the score, the maps and the picks and bans, but only while the next match that depends on it has no result yet. Undo that one first.
